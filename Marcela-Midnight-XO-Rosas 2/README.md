# Para Marcela — Midnight XO

Proyecto estático de HTML, CSS y JavaScript para una carta digital personalizada.

## Archivos

- `index.html`: página principal con el sobre, la carta y el ramo de seis rosas.
- `styles.css`: estilos responsivos y estética nocturna Midnight XO.
- `script.js`: apertura y cierre de la carta, reproductor de audio y notas sorpresa.
- `assets/`: fotografías, audio, portada del álbum As You Are y la ilustración SVG del ramo.

## Cómo abrirlo

1. Extrae la carpeta del ZIP.
2. Abre `Marcela-Midnight-XO-Rosas` en Visual Studio Code.
3. Abre `index.html` en el navegador o inicia Live Server desde VS Code.

Las fotografías y el audio se cargan desde la carpeta `assets`; por eso, conserva la estructura de archivos al mover el proyecto.

## El ramo

La ilustración `assets/ramo-seis-rosas.svg` contiene exactamente tres rosas rojas y tres blancas. El texto de la sección recuerda que fue el ramo con el que le pediste a Marcela ser tu novia y conecta las flores con paz, amor y pasión. Puedes editar el SVG o cambiar su tamaño desde `.rose-art` en `styles.css`.


Se añadió una línea de tiempo con las dos fechas especiales: primer beso (11 de abril de 2026) y el día en que comenzaron oficialmente la relación (11 de julio de 2026).


La canción se actualizó a “As You Are” de The Weeknd usando el audio proporcionado, y se incorporó la portada enviada.
